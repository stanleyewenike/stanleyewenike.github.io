Heart disease prediction: a reproducible analytical pipeline

Organisation
Personal project (technical assessment)
Role
Sole author
Period
2026

An end-to-end logistic regression pipeline that predicts heart disease from the public UCI heart disease dataset. It is built to reproducible analytical pipeline (RAP) principles.

Situation

The UCI dataset has 919 records and 16 variables.

Task

Build a model that reruns reproducibly and is evaluated honestly, and document how it meets RAP principles.

Action

  • Built a configuration-driven pipeline with a stratified train/test split (736 / 184).
  • Avoided leakage between training and test data.
  • Trained logistic regression with 5-fold cross-validation and evaluated it on the held-out test set.
  • Wrote run outputs to a JSON summary, and mapped each RAP principle to evidence in the repository.

Result

Cross-validated AUC 0.890 (± 0.019); test AUC 0.918, recall 0.902, precision 0.829 and F1 0.864.

Skills and tools

Python, pandas, scikit-learn, cross-validation, ROC and AUC evaluation, RAP principles, git.

What I learnt

  • Report cross-validated and held-out results together. When they agree, that is evidence of no leakage.
  • Mapping principles to evidence makes reproducibility checkable rather than claimed.
  • The next steps are a simple reference model and a calibration check.
