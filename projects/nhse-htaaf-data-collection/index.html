Benefits and outcomes data collection for a technology adoption fund

Organisation
NHS England
Role
Evaluation Senior Manager and Analytics Lead
Period
2024

I redesigned the quarterly template that Integrated Care Boards (ICBs) use to report the benefits and outcomes of the Health Technology Adoption and Accelerator Fund, linking it to the programme's outcomes model.

Situation

The programme spans 7 technology categories and more than 100 adoptions. The existing template was not structured around the outcomes model, so returns were hard to compare.

Task

Build a template that captures outcome metrics consistently across ICBs, products and technology categories without adding reporting burden, and pilot it.

Action

  • Built the outcomes model hierarchy (ICB, product, technology, metric) into the template.
  • Split the evaluation section by technology category.
  • Added lookup-driven dropdowns and data validation, so returns use controlled lists rather than free text.
  • Piloted a cut-down version with one ICB over four iterations, then finalised it.

Result

A final 18-sheet template with built-in validation, piloted with one ICB.

Skills and tools

Excel template design (lookups, validation), outcomes and benefits frameworks, data collection design, stakeholder piloting.

What I learnt

  • The quality of an evaluation is decided when the data collection is designed.
  • Piloting with one organisation finds usability problems early and cheaply.
  • Pair a template with a validation script, so returns are checked as soon as they arrive.
