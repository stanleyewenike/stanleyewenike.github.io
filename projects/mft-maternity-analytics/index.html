Maternity analytics: customised growth centiles

Organisation
Manchester University NHS Foundation Trust
Role
Senior Information Analyst
Period
2020

I prepared maternity system data for bulk calculation of GROW customised birthweight centiles, which are used to identify small-for-gestational-age babies and fetal growth restriction. I also supported a regional maternity dashboard.

Situation

Maternity data sat in several systems, and the centile calculator needed a specific input format.

Task

Produce the calculator input, process its output, and keep the regional dashboard data flowing.

Action

  • Wrote SQL to build the bulk centile calculator input from the maternity systems, and to load and process the results.
  • Ran and supported an existing regional maternity dashboard script.

Result

Centile outputs were ready for monitoring small-for-gestational-age babies and fetal growth restriction, and the regional dashboard continued to receive data.

Skills and tools

SQL, maternity data (SMMIS, K2), GROW customised centiles, regional dashboard support.

What I learnt

  • Clinical calculators depend on exact input specifications, so validate the mapping field by field.
  • In short roles, keep a brief log of what you delivered.
