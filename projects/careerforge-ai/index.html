CareerForge AI: career decision support

Organisation
Personal project
Role
Sole designer
Period
2026

CareerForge AI is a career decision-support tool for people running many job applications at once. The working prototype is a library of 14 Claude skills covering the application cycle, from decoding a job advert to planning the first 100 days in a new role. A spreadsheet tracker scores and ranks every role.

Situation

People applying for many roles at once, often across several sectors, need a tailored CV, cover letter or supporting statement for each one.

Task

Build a repeatable way to decide which roles deserve full effort, and to produce tailored, accurate materials without inventing experience.

Action

  • Built a pipeline tracker that scores each role on nine weighted dimensions, including fit, likelihood of success, strategic value, salary and location.
  • Turned the workflow into 14 skills covering seven stages, from research and assessment to interview preparation and post-offer planning, plus pipeline management. Each skill has triggers, steps, an output format and quality checks.
  • Grounded the employer-research skill in web search, so materials draw on current information about each employer.
  • Set a shared rule against invented experience, and specified human confirmation before the platform sends anything.
  • Specified a full platform: about 60 functional requirements, a phased release plan, a cloud architecture and a 16-week first release.

Result

A working prototype. The platform itself is not yet built.

Skills and tools

Claude skills and prompt design, web-search grounding, Excel, product requirements and release planning, solution architecture.

What I learnt

  • Deciding where to spend effort matters more than polishing any one application.
  • AI skills need an explicit rule against invented content, and a human check before anything leaves the system.
  • Prove a workflow with skills and a spreadsheet before writing code. My next step is a personal app with tests.
