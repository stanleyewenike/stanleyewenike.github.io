Reproducible pipeline for analysing assurance returns

Organisation
NHS England
Role
Evaluation Senior Manager and Analytics Lead
Period
2025

I built a four-stage Python reproducible analytical pipeline (RAP). It reads 15 narrative assurance returns from Word documents, scores them with rule-based text analysis, and generates the summary presentation automatically.

Situation

The assurance returns were free-text Word documents. Analysing them by hand each quarter would be slow and hard to repeat consistently.

Task

Turn the returns into scored, structured data and a presentation, following RAP principles.

Action

  • Stage 1 extracts paragraph and table text with python-docx.
  • Stage 2 applies documented rules: a timeliness score against target, risk themes, sentiment and confidence indicators, and detection of the systems each network uses. Maturity tiers are assigned from a lookup table.
  • Stage 3 prints a console summary, including the number of returns processed against the expected 15.
  • Stage 4 builds 10 charts and the PowerPoint deck with matplotlib and python-pptx.
  • Wrote a README and a methodology playbook that explain the scoring rules.

Result

The charts and summary deck can be regenerated from the source documents, with structured JSON outputs available for further analysis.

Skills and tools

Python (python-docx, python-pptx, matplotlib, pandas, regular expressions), rule-based text analysis, RAP design, automated reporting.

What I learnt

  • Lookup tables need a test that every expected key is present. Without one, mismatches fail silently.
  • The pipeline is only the source of truth if published figures come from it unchanged.
  • I carried these lessons into a later pipeline, where the tests run as a gate.
