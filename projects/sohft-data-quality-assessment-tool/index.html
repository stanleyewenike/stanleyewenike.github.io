Data Quality Assessment Tool

Organisation
Southport and Ormskirk Hospital NHS Trust
Role
Data Quality Analyst
Period
2021

I built a SQL-based Data Quality Assessment Tool and a set of targeted checks covering NHS number validity, duplicate records, A&E data quality and outpatient outcomes. The tool was designed to run daily and feed a reporting dashboard.

Situation

Data quality checks were ad hoc. There was no standard denominator, no stored results and no routine way to see trends.

Task

Build a repeatable assessment tool and the specific checks the data quality team needed.

Action

  • Wrote daily and monthly versions of the assessment tool, and compared versions for efficiency.
  • Prototyped a production version: a denominator table, a results table, views, a stored procedure, a scheduled job and an SSRS dashboard.
  • Wrote a reusable SQL function implementing the NHS number Modulus 11 check.
  • Built checks for duplicate NHS numbers, A&E data quality, outpatient attendances with no outcome, and maternity recording.
  • Built a date dimension and an SPC query for the trust's integrated performance report.

Result

The trust gained a reusable set of data quality checks and a design for automated daily monitoring.

Skills and tools

T-SQL (functions, stored procedures, views, scheduled jobs), SSRS, data quality dimensions, NHS number validation, statistical process control.

What I learnt

  • Data quality monitoring needs stored denominators and results history, or trends cannot be seen.
  • Reusable validation functions remove a whole class of repeated code.
  • Record a baseline at the start of any data quality work.
