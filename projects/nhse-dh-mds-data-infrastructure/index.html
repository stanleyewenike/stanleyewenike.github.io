Data infrastructure design for a national minimum dataset

Organisation
NHS England
Role
Evaluation Senior Manager and Analytics Lead
Period
2025

I designed the internal data platform to receive, validate and report on a minimum dataset submitted by the 15 Health Innovation Networks. The design covered the architecture, the data models and synthetic test data.

Situation

Networks submitted CSV files exported from a spreadsheet tool. There was no central store, no automated validation and no reporting layer.

Task

Design infrastructure to store and report on the dataset, and define the data models it needs.

Action

  • Designed a lakehouse architecture on Azure. Files land in a data lake, Databricks Auto Loader brings them in, and they move through bronze, silver and gold Delta tables. Automated validation follows, then Power BI or Tableau reporting, with role-based access and monitoring throughout.
  • Modelled the data at three levels: 5 conceptual entities, a 6-table entity relationship diagram, and a dimensional model with 5 dimensions and 2 fact tables.
  • Built a synthetic data generator with Python Faker, so pipelines could be tested without real data.
  • Documented the design in Markdown and Mermaid.

Result

  • Senior leadership in the directorate thanked me in writing for designing the infrastructure that stores and reports on the minimum dataset.
  • A partner organisation later delivered the physical database, informed by this design.

Skills and tools

Data architecture (medallion pattern, lakehouse), Azure Data Lake, Databricks and Delta Lake (architecture design), data validation, ERD and dimensional modelling, Mermaid, Python Faker.

What I learnt

  • Design the data model first. The choice of tools follows from it.
  • Synthetic data lets pipelines be built and tested safely before access to real data is approved.
  • Senior stakeholders trust architecture documents that show the security and validation layers explicitly.
