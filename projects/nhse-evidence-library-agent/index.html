Evidence agent for an evaluation library

Organisation
NHS England
Role
Evaluation Senior Manager and Analytics Lead
Period
2026

I built a Microsoft 365 Copilot agent that answers questions from my team's SharePoint evidence library. Its instructions require it to retrieve before it answers, cite its sources, grade the strength of each piece of evidence, keep caveats next to the claims they qualify, and say so when the library cannot support an answer. I also designed the tests that decide whether it is ready for wider use.

Situation

The library holds evaluation reports, methods and corrections. Evaluation evidence changes meaning when its caveats are lost: a correct number can mislead once its denominator or causal caveat disappears. The agent's first instructions had been written for an engineering assistant, not an evidence assistant.

Task

Make the agent answer only from the library, never state a claim more strongly than its evidence, and abstain when the evidence is insufficient. Then define how to test it.

Action

  • Kept the library as the agent's only knowledge source, with general model knowledge discouraged.
  • Rewrote the instructions as a grounding policy:
    • seven evidence-strength classes, from directly evidenced finding to unsupported claim;
    • rules against turning association into causation, candidate matches into confirmed identities, or missing data into zero;
    • a source-precedence order for corrected and superseded material;
    • a fixed abstention statement;
    • a final grounding check before each answer.
  • Wrote a 12-section implementation checklist, covering library readiness, hard grounding tests, provenance, permissions, user acceptance testing and a go or no-go release decision.
  • Designed and ran a 20-question benchmark across answerable, partially answerable and unanswerable cases, built on programme evidence I produced. Each answer is scored on six dimensions, including claim fidelity and caveat preservation, and critical failures override the total score.

Result

The revised agent is deployed with the new grounding policy, and I ran the benchmark against it in October 2026.

Skills and tools

Microsoft 365 Copilot agents, retrieval-augmented generation on a managed platform, instruction design for grounded answers, evaluation benchmark and rubric design, adversarial testing, evaluation methodology.

What I learnt

  • For an evidence agent, the instructions are evaluation rules: what a claim may and may not be upgraded to.
  • Curate the library before tuning the prompt.
  • Test the hard cases, such as unanswerable questions, conflicting sources and requests to drop the caveats, more than the easy lookups.
