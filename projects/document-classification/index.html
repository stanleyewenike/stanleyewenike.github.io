Document classification and entity extraction

Organisation
Personal project (technical challenge)
Role
Sole author
Period
2026

A pipeline that turns scanned documents into text with OCR, classifies each page with a zero-shot transformer model and keyword rules, and extracts key entities.

Situation

A set of scanned pages had to be classified into four document types, with no labelled training data.

Task

Build a working pipeline from image to structured output, and explain the design.

Action

  • Extracted text with Tesseract OCR.
  • Classified pages with a zero-shot model (facebook/bart-large-mnli).
  • Added a keyword-heuristic classifier tuned on the OCR output, which returns a category, a confidence score and the method used.
  • Extracted entities with regular expressions and spaCy named entity recognition.
  • Wrote 13 unit tests.

Result

A tested, end-to-end document-processing pipeline.

Skills and tools

Python, Tesseract OCR, Hugging Face Transformers (zero-shot classification), spaCy, regular expressions, pytest.

What I learnt

  • Zero-shot models are a fast starting point when labels don't exist, but they still need a labelled check before production use.
  • OCR quality limits everything after it.
  • The next steps are an evaluation set and a confidence threshold that routes uncertain pages to human review.
